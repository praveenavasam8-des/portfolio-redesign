## HOW TO UPLOAD TO BEHANCE

### Step-by-Step Instructions:

1. **Create/Login to Behance Account**
   - Go to behance.net
   - Sign up or login with Adobe ID

2. **Set Up Your Profile**
   - Upload profile photo
   - Write compelling bio (3-4 sentences)
   - Add location & links (Wix portfolio, LinkedIn, etc.)
   - Add your design skills & specialties

3. **Start New Project**
   - Click "Share Your Work"
   - Fill in project title
   - Add cover/hero image (1920x1080px recommended)
   - Write project description (2-3 paragraphs)

4. **Upload Project Images**
   - Add images in correct order (process → outcome)
   - Use high-quality images (minimum 1200px width)
   - Add captions to key images
   - Ensure 3-10 images per project

5. **Add Project Details**
   - Add tags (max 8-10 relevant tags)
   - Specify tools used (Figma, Fusion 360, etc.)
   - Choose project category
   - Set project visibility (public/private)

6. **Publish & Share**
   - Review all content
   - Publish project
   - Share on social media & portfolio

## RECOMMENDED IMAGE SPECIFICATIONS

- **Cover/Hero Image:** 1920x1080px, high quality
- **Gallery Images:** 1200x1000px minimum
- **Format:** JPG or PNG
- **Quality:** High resolution (72 DPI min, 300 DPI preferred)
- **Aspect Ratio:** Vary between 16:9, 4:3, and square (1:1) for visual interest

## CONTENT WRITING TIPS FOR BEHANCE

**Do:**
- Lead with the problem & user need
- Explain your design thinking
- Show process, not just final outcome
- Use clear, concise language
- Include metrics & measurable outcomes
- Highlight your unique approach

**Don't:**
- Use overly technical jargon
- Forget to explain "why" behind decisions
- Upload low-quality images
- Write too much text (keep it scannable)
- Neglect to show your process
